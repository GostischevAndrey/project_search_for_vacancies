# Проект 2. Поиск вакансий

## Описание проекта

Этот проект предоставляет инструменты для поиска, фильтрации, сортировки и сохранения вакансий с использованием API
HeadHunter. Проект включает в себя классы для работы с вакансиями, их фильтрации, сортировки и сохранения в JSON-файл.

## Зависимости проекта:

* python = "^3.13"
* requests = "^2.32.3"
* pytest = "^8.3.5"
* pytest-cov = "^6.0.0"

## Основные компоненты

### 1. `base_api.py`

Содержит классы для работы с API HeadHunter:

- `BaseVacancyAPI` — абстрактный класс для работы с API.
- `HeadHunterAPI` — реализация класса для загрузки вакансий с HeadHunter.

### 2. `base_json.py`

Содержит классы для работы с JSON-файлами:

- `Worker` — абстрактный класс для чтения и записи файлов.
- `JSONSaver` — реализация класса для сохранения и чтения вакансий в JSON-файл.

### 3. `utils.py`

Содержит класс `FilterSortVacancies` для фильтрации, сортировки и вывода топ вакансий:

- Фильтрация по ключевому слову в описании.
- Фильтрация по городу.
- Фильтрация по зарплате.
- Сортировка по зарплате.
- Вывод топ N вакансий.

### 4. `vacancy.py`

Содержит класс `Vacancy` для работы с данными вакансий:

- Хранение информации о вакансии (название, ссылка, зарплата, описание, город).
- Сравнение вакансий по зарплате.

### 5. `config.py`

Модуль определяет пути к корневой директории проекта (ROOT_DIR) и директории для хранения данных (DATA_DIR).

### 6. `main.py`

Модуль для запуска программы и взаимодействия с пользователем через командную строку.

## Инструкция по установке

- Чтобы скачать репозиторий:

```commandline
https://github.com/GostischevAndrey/project_search_for_vacancies
```

- Установите зависимости с помощью `poetry`:
```commandline
poetry install
```
- Активируйте виртуальное окружение:
```commandline
poetry shell
```

## Тестирование

Проект протестирован Pytest.
Проект покрыт тестами на 100%.

Чтобы запустить тесты с оценкой покрытия выполните команду

```commandline
poetry run pytest --cov
```

Чтобы сгенерировать отчет о покрытии в HTML-формате, где src — пакет c модулями, которые тестируем.
Отчет будет сгенерирован в папке htmlcov и храниться в файле с названием index.html
.

```commandline
pytest --cov=src --cov-report=html
```
